# Soporte

## Cómo presentar incidencias y obtener ayuda

Este proyecto utiliza las incidencias de GitHub para rastrear errores y solicitudes de funciones. Por favor, busque las incidencias existentes antes de crear nuevas para evitar duplicados. Para nuevos casos, presente su error o solicitud de función como una nueva incidencia.

Para ayuda o preguntas sobre el uso de este proyecto, por favor abra una incidencia.

## Política de soporte en GitHub

El soporte para este proyecto está limitado a los recursos indicados arriba.
