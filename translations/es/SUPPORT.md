# Soporte

## Cómo reportar problemas y obtener ayuda

Este proyecto utiliza los issues de GitHub para rastrear errores y solicitudes de funciones. Por favor, busque en los issues existentes antes de crear uno nuevo para evitar duplicados. Para nuevos reportes, presente su error o solicitud de función como un issue nuevo.

Para obtener ayuda o hacer preguntas sobre el uso de este proyecto, por favor abra un issue.

## Política de soporte de GitHub

El soporte para este proyecto se limita a los recursos listados arriba.
